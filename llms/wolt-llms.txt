# Wolt

> Wolt is a marketplace and last-mile delivery platform. Its developer surface exposes the Order/Marketplace API (receive and fulfill consumer orders through a POS/in-store system) and the Wolt Drive API (on-demand last-mile delivery: shipment promises, deliveries, tracking, and webhooks). Auth is OAuth 2.0 (bearer JWT); Wolt Drive uses a Merchant Key bearer token.

## APIs
- [Order / Marketplace API](https://developer.wolt.com/docs/api): Receive and manage consumer orders (accept, ready, delivered, refunds). Base paths /orders and /v2/orders.
- [Wolt Drive API](https://developer.wolt.com/docs/wolt-drive/endpoints): Last-mile delivery. Production https://daas-public-api.wolt.com, dev https://daas-public-api.development.dev.woltapi.com.
